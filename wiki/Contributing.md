# 🤝 Contributing

Results from a built board are the most valuable contribution.

## Most useful

1. **Build one** and post results: photos, scope captures of A/B, rail voltages, what broke.
2. **Verify** items on [[Known Issues]] and report the outcome.
3. **Firmware:** flash `tools/build.sh ghostlight-rev1` onto a built board and report what works.
4. **Docs:** fix mistakes, add enclosure drawings, assembly photos.

## Workflow

- Open an [issue](https://github.com/DefeatedWarrior/ghostlight-node/issues) for bugs and questions.
- Pull requests are welcome. For hardware changes, say which design file changed and why. The KiCad files are generated by scripts in `tools/generator/`, so edit the generator or note that the KiCad file was edited directly.

## Regenerating the design

The board and schematic were produced by Python scripts in `tools/generator/` (KiCad 7 + pcbnew, Freerouting 1.9.0). They are reference only and the routed board is not reproducible bit-for-bit. See [`docs/14`](https://github.com/DefeatedWarrior/ghostlight-node/blob/main/docs/14-regenerating-the-design.md).
